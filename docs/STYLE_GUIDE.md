# Style Guide

## Button / CTA text

All button and CTA labels use **Title Case** (e.g. "Book a Demo", "See in Action") — not
UPPERCASE and not sentence case. This applies to `.cta-button` labels (`components/ui/Button.tsx`)
and any new CTA added anywhere on the site. The arrow icon (`→`) stays a separate element
after the label, not part of the text.

Reference implementation: `components/sections/FinalCta.tsx` ("Book a Demo →").
